\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

In an organizational context shaped by diverse skills, fast-changing projects and the need for cross-functional oversight, companies require tools that consolidate information and anticipate imbalances. This work focuses on Strategic Copilot: an intelligent SaaS decision-support platform for strategic talent and project management. The platform supports managers, HR staff and talents through interactive dashboards, smart alerts and AI-based recommendations to manage skills, workloads and the project portfolio effectively.

The objective of this end-of-study project is to design and implement an integrated web solution that provides HR and project KPI visualization, risk detection (overload, contract expiry, skill gaps), project viability analysis, automated AI recommendations and HR request management within automated decision workflows, with an experience tailored to each user profile.

The approach combines requirements analysis, use-case definition per business workspace (manager, HR, talent), application architecture design and iterative development of a React.js front end with Vite and Tailwind CSS. Integration uses Supabase and PostgreSQL for storage, authentication and APIs, n8n for process orchestration and the Llama model for decision support. Testing and validation phases refined the features against priority scenarios.

The platform turns business data into actionable insights through role-based dashboards, risk detection (overload, contract end dates, skill shortages), project viability analysis, a \emph{what-if} simulator, a decision log, and structured HR request workflows. The embedded \emph{Strategic Copilot} provides summaries, viability scores, recommendations, and a context-aware conversational assistant (project, team, alerts), powered by the \textbf{Llama} model and supported by automated orchestration flows.

The methodology combines requirements analysis, a modular multi-role architecture (manager, HR, and talent workspaces), and iterative development of a React front end (Vite, Tailwind CSS) connected to Supabase (PostgreSQL, authentication, API) and n8n for automation. Validation on critical user journeys---project steering, HR request handling, and talent self-service---confirms consistent alerting, useful recommendations, and a coherent multi-stakeholder experience.

\textbf{Keywords:} SaaS, Artificial Intelligence, Talent Management, Project Management, Decision Support.
